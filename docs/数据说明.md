## 1. 数据来源

本研究使用 Kaggle Datasets 公开数据集 **Wild Blueberry Yield Prediction**
（`saurabhshahane/wild-blueberry-yield-prediction`），其内容为 2020 年发表于
《Computers and Electronics in Agriculture》的研究所发布的仿真数据集
（Obsie, Qu & Drummond, 2020），原始版本托管于 Mendeley Data，DOI `10.17632/p5hvjzsvn8.1`，
采用 CC BY 4.0 许可。

**关于选题**：最初拟使用 Kaggle 竞赛 `DeepBlueberry Challenge 2025` 的数据。
该竞赛为**邀请制**，数据接口需参赛者身份认证，非受邀者无法获取，因此改用公开数据集。

二者关系经逐行比对确认为：**同一套仿真模型的两批独立运行结果，不是母本与副本**。
竞赛版中每个场景约重复仿真 19 次、每次环境参数重新抽样，因此按 `Row#` 对齐后，
16 个特征完全相同的行仅 **1 / 15,000**，同一 `Row#` 下 `fruitset` 的一致率仅 **0.4%**。
本版则是每个场景一条原始记录，条件与产量的对应关系完整保留。同源佐证是两版的
`yield` 极值完全相同（min 1637.704022 / max 8969.401842）。

任务目标（用环境、生物、气候特征回归预测蓝莓产量）、特征集合（16 列）与评估指标（MAE）
完全一致；但两版数据的信噪比不同——温度六列与 `yield` 的相关系数在本版约为 **−0.18**，
在竞赛版中接近 0（**−0.004**），因为重复仿真把温度作用平均掉了。因此**两版分数不可直接比较**。

**获取方式**：Kaggle Datasets 的公开下载端点无需登录、无需 API Token，可脚本化复现：

```bash
python src/data/fetch_dataset.py
```

支撑该方式可用的依据是实测结果：`https://www.kaggle.com/api/v1/datasets/download/{owner}/{dataset}`
对公开数据集返回 200 并直接给出 zip 文件。

## 4. 数据质量核验

执行 `python src/data/validate_data.py`，共 16 项检查，结果 **13 通过 / 3 警告 / 0 失败**。

### 4.1 通过项

| 检查 | 结果 |
| --- | --- |
| 文件指纹 | md5 与 Kaggle 数据集原件一致 |
| 行列规模 | 777 × 18，与数据集声明一致 |
| 列名与顺序 | 与字段定义完全一致 |
| 列类型 | 18 列全数值型，无需类别编码 |
| 缺失值 | **0** |
| 完全重复行 | **0** |
| 数值有限性 | 无 inf / -inf |
| 常量列 | 无，16 个特征均有取值变化 |
| 离散特征取值 | 13 列取值种类在 3–12 之间，符合模拟实验设计的固定网格 |
| `yield` 极值 | min 1637.704022 / max 8969.401842，与学术原件精确一致 |
| `yield` 有效性 | 全为正，均值 6012.85，标准差 1356.96 |

### 4.2 三项警告（不阻塞，但影响方案选择）

**警告一：果实类特征与目标高度相关。**

| 特征 | Pearson r |
| --- | --- |
| `fruitset`（坐果率） | **+0.9841** |
| `seeds`（种子数） | +0.9612 |
| `fruitmass`（单果质量） | +0.9304 |

三者共同解释了产量绝大部分方差，本数据的预测信号高度集中在果实类指标上。
这符合生物学机理：坐果率直接决定果实数量。它们**不是泄漏特征**，而是真实的因果前驱，
因此保留。

**警告二：温度六列近乎完全共线。** 六列两两最高 |r| 达 0.9999，
实质上是同一温度区间的六种统计口径。多重共线性会放大线性模型系数的不稳定性，
但基于正则化的模型（Ridge）与树模型不受影响。

**警告三：特征量纲差异大。** 各特征极差最大相差 **147 倍**
（`clonesize` 极差 30，`RainingDays` 极差 33，而 `bumbles` 极差仅 0.585）。
线性模型与神经网络必须先标准化，否则结果被大量纲特征主导。

### 4.3 数据真实性核验

为避免"数据是否为人工编造"的质疑，另做独立溯源验证
（`python src/data/verify_provenance.py`，6 项全部通过）：

1. **本地文件指纹**与数据集原件 md5 一致；
2. **两个互不相干的 Kaggle 上传者**（`saurabhshahane` 与 `shashwatwork`）各自公开的数据集中，
   内含的 CSV **逐字节完全相同**（同一 md5 `feffa3af…`）。两个独立用户不可能上传出
   逐字节相同的伪造文件，这排除了单点造假；
3. **规模 777 行**与该数据集声明的记录数一致；
4. **13 个离散特征的取值构成固定网格**（如 `clonesize` 仅 6 种、各温度字段仅 5 种），
   这是计算机模拟实验设计的产物，随机生成的数据不具备此类结构；
5. **`yield` 极值**（1637.704022 / 8969.401842）与学术原件精确到小数点后 6 位一致；
6. **DOI 可查**：Mendeley Data `10.17632/p5hvjzsvn8.1` 公开可访问。

## 5. 数据划分方案

由于数据无预置测试集，并按团队统一口径切分，采用两层协议：

| 子集 | 行数 | 占比 | 用途 |
| --- | --- | --- | --- |
| **CV 区**（`fold_id` 0–4） | 621 | 80% | 5 折交叉验证，日常迭代 |
| **Holdout**（`fold_id` = -1） | 156 | 20% | 冻结，仅最终定模后评估 |

- 切分脚本：`src/data/make_folds.py`，`random_state = 42`，按 `yield` 十等分箱分层抽样，
  保证各子集产量分布一致；
- 每折验证 124–125 行、训练约 496 行；
- 划分结果保存在 `data/processed/folds.csv`，全组共用同一份，任何人不得自行重新切分；
- 脚本绑定数据文件 md5，数据一旦变化会强制重算，避免"数据换了、折没换"的静默错误。

**为什么不用简单 8:2 单次划分**：单人建模时，单一验证集的划分方式会显著影响结论，
不同人切分不同则分数不可横向比较；且反复在同一验证集上调参会使其"被调穿"。
5 折交叉验证 + 独立 holdout 兼顾了评估稳定性与终检的客观性。

## 6. 基线结果

在统一折划分上的实测结果（`python src/data/baselines.py`）。

| 模型 | OOF MAE | 每折均值 ± 标准差 |
| --- | --- | --- |
| 常数基线（训练折均值） | 1103.77 | 1103.79 ± 8.88 |
| **Ridge（StandardScaler, α=1）** | **98.79** | 98.78 ± 6.58 |
| RandomForest（默认, 100 棵） | 123.14 | 123.12 ± 8.54 |
| HistGradientBoosting（默认） | 116.49 | 116.49 ± 8.15 |

**一个值得在报告中讨论的现象**：线性模型（Ridge, 98.79）明显优于两种集成树模型（116–123）。
原因有两点：其一，`fruitset` 与 `yield` 的关系近似线性（r = 0.984），线性模型已能捕捉主要信号；
其二，每折训练集仅约 496 行，树模型容量过剩、易在训练集上过拟合。
这说明**在本数据上，模型复杂度不是瓶颈，特征表达与正则化才是**。

同时，所有模型相对常数基线（1103.77）的误差下降幅度均超过 88%，
表明这 16 个特征对产量具有强解释力。

## 7. 使用规范

1. **预处理只能在训练折内 `fit`**，标准化、编码等一律不得使用验证折或 holdout 的统计量。
2. **`Row#` 不得作为特征**，可用特征为上述 16 列。
3. **不得用 `yield` 派生任何特征**（含目标编码、分组均值等）。
4. **holdout 仅用于最终评估**，不得用于调参、早停或模型选择。
5. 报分统一使用 **OOF MAE**（5 折验证预测拼接后整体计算），不使用折间平均。
6. 由于每折验证集仅 124 行，模型间 **MAE 差距小于约 5 时不宜视为显著差异**。

## 9. 局限性

1. **样本量偏小（777 行）**。每折验证仅 124 行，指标存在约 ±6–9 的折间波动，
   小幅度模型差异不可靠；深度神经网络在此规模下难以体现优势。
2. **数据为模拟数据，非田间实测**。原始研究以经过 30 年田间观测校准的授粉模拟模型生成，
   能够反映生物学机理，但不等同于真实农场的产量波动。
3. **特征为实验设计网格值**，13 个离散特征的取值来自模拟实验的预设水平，
   而非连续观测，模型在网格外的外推能力未经验证。
4. **温度六列高度共线**，独立解释各自效应存在困难。
