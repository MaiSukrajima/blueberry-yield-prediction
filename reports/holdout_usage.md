# holdout 使用登记表

**holdout 规模：156 行（20%）**，由 `src/data/make_folds.py` 用 `random_state=42` 生成，
`fold_id = -1`，与 CV 区的 621 行完全不重叠。

## 规则

- 每人**最多使用 3 次**，用一次记一次。
- holdout **只用于最终定模后评估一次**。
- 禁止用途：早停、调参、模型选择、特征筛选。
- 违反即视为分数不可信。

## 为什么必须冻结

CV 区的 621 行会被全组反复用来选模型、调参，它本身已经被"信息泄漏式"地用了几十次。
holdout 是唯一还能说真话的那 156 行。一旦拿它调参，就没有任何东西能检验泛化能力了。
